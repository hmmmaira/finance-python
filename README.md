# Finance Python

A personal finance and quantitative research workspace focused on applying Python to financial analysis, equity research, portfolio management and quantitative methods.

## Objectives

- Develop Python programming skills for financial applications.
- Analyse financial market data using pandas and NumPy.
- Perform equity valuation and financial statement analysis.
- Build portfolio optimization and risk analytics tools.
- Develop quantitative research projects.

## Project Structure

- `notebooks/` — Jupyter notebooks and financial analysis.
- `scripts/` — Reusable Python scripts and functions.
- `data/` — Raw, processed and sample datasets.
- `outputs/` — Charts, reports and Excel exports.

## Technology Stack

Python 3.12, pandas, NumPy, matplotlib, seaborn, yfinance, SciPy, statsmodels, openpyxl and xlsxwriter.

## Setup

Create and activate a virtual environment, then install dependencies:

```bash
pip install -r requirements.txt
```

## Learning Roadmap

A 16-week practical Python programme covering financial mathematics, market data analysis, equity valuation, portfolio optimization, quantitative research and portfolio monitoring.
